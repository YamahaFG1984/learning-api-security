Natter API · 中文教学版

API 安全实战教程

本教程基于 Manning 出版社图书《API Security in Action》（Neil Madden 著）配套的 Natter 项目整理而成。 原书用 Java + Spark 框架，围绕一个社交类 API "Natter" 逐章加固安全性 —— 从最基础的输入校验、密码认证， 一路讲到 OAuth2、JWT、mTLS、Kubernetes 微服务安全，直到物联网设备的端到端加密。 每一章都配有大量图解和真实项目代码，帮助完全没有安全背景的开发者，从"是什么、为什么危险、怎么防" 三个层次理解每一个安全机制。

13 章教程 中文讲解 图解优先 Java/Spark ⇄ Python/Django ⇄ TypeScript/Hono.js
🧩

为什么每章都有三栏代码？ 原书代码是 Java + Spark 微框架实现的。为了让熟悉 Python 或 Node.js 生态的读者也能对照学习， 每个关键安全机制都额外给出了 Django（Python） 和 Hono.js（TypeScript） 的等价实现，三栏内容实现的是同一件事，方便你按自己熟悉的技术栈理解、也能顺带学到另外两个栈的写法。 少数章节（如第 12、13 章的部分内容）涉及协议层/嵌入式场景，和具体 Web 框架关系不大，页面里会如实说明， 不会为了凑数编造不存在的 API。

Part 1 · 基础篇
第 1 章

什么是 API 安全？

用"考驾照"类比理解认证与授权；资产、安全目标、威胁模型；五大安全机制总览。全书概念地图。
第 2 章

安全的 API 开发

认识 Natter 项目；SQL 注入、输入校验、XSS 与安全输出 —— 写代码时就该避免的基本坑。
第 3 章

为 Natter API 加固安全

限流、密码认证、HTTPS/HSTS、审计日志、访问控制列表 —— 六大安全机制第一次集中登场。
Part 2 · 基于 Token 的认证
第 4 章

基于会话 Cookie 的认证

Session Cookie、会话固定攻击、CSRF 攻防、SameSite 与双重提交 Cookie。
第 5 章

现代化的基于 Token 的认证

CORS 跨域、Bearer Token、数据库存储 token、用 HMAC 加固 token 防篡改。
第 6 章

自包含 Token 与 JWT

JWT 三段结构、签名与加密、认证加密（AEAD）、token 撤销的混合方案。
Part 3 · 授权
第 7 章

OAuth2 与 OpenID Connect

授权码 + PKCE 完整时序、访问令牌校验、单点登录、OIDC ID Token。
第 8 章

基于身份的访问控制

用户与组、RBAC 角色权限映射、ABAC 属性策略、策略代理与网关。
第 9 章

基于能力的安全与 Macaroon

能力 URI、HATEOAS、confused deputy 问题，以及 Macaroon 的 HMAC caveat 链。
Part 4 · Kubernetes 中的微服务 API
第 10 章

Kubernetes 中的微服务 API

容器化部署、Kubernetes 架构、SSRF 与 DNS rebinding 攻防、service mesh mTLS。
第 11 章

保护服务间调用的 API

Client Credentials Grant、JWT Bearer 认证、mTLS、幻影令牌模式、密钥管理。
Part 5 · 物联网 API
第 12 章

保护物联网通信

DTLS、预共享密钥、COSE 端到端加密、密钥棘轮与前向保密。
第 13 章

保护物联网 API

设备认证、OSCORE、Device Authorization Grant、离线访问控制、全书回顾。
根据 Neil Madden《API Security in Action》(Manning, 2020) 及其配套 Natter 项目源码整理， 补充 Django / Hono.js 等价实现用于教学对比。
